File structure humans can trace

A clean-break proposal that groups every workflow artifact by run, phase, task, and turn—while keeping durable product documents in Git.

01 · Architecture decision

Hybrid, lifecycle-first storage

The recommended design separates durable documentation from ignored execution evidence. A run manifest connects both sides, so a human starts from one place and follows the complete chain.

Alternative A

Everything inside the run

Maximum locality, but committed documentation and disposable worker evidence become mixed together.

Recommended

Durable docs + run evidence

Versioned product knowledge stays under docs/. Operational evidence stays under one run-scoped directory.

Alternative C

Current paths + generated index

Small migration, but the fragmented layout remains the source of truth and continues leaking into skills.

04 · Proposed additions

Minimum templates worth owning

These additions close structural gaps. Raw output, native scaffold files, and deterministic extracts remain template-free.

discovery-template.md

Research question, evidence, four research domains, risks, synthesis, and proposed backlog.

document-companion-template.html

One accessible shell for design and plan HTML, rendered deterministically from Markdown.

run-manifest.schema.json

Workflow ID, topic, lifecycle state, artifacts, producers, templates, dependencies, timestamps, and Git SHAs.

run-index-template.md

A generated human timeline with links to every phase, task, turn, and published document.

message-envelope.schema.json

A real JSON Schema replacing the current descriptive protocol object.

ledger-entry.schema.json

Validation for append-only dispatch pairs and author/provider metadata.

task-report-template.md

Implementation summary, changed files, tests, RED/GREEN evidence, self-review, concerns, and blocked operations.

retrospective-template.md

Measured outcomes, evidence, approved actions, owners, and follow-up status.

constitution-template.md

Stack, standards, commands, conventions, quality gates, and decision authority.

tool-instruction-template.md

A minimal pointer to CONSTITUTION.md plus a strictly tool-specific section.

Deliberate deletion: remove .superpowers/sdd/progress.md. Progress belongs in manifest.json; maintaining both would create drift.

05 · Migration shape

Move consumers in five bounded stages

1. ContractsAdd schemas and template validation.
2. Run resolverOne script owns all run paths.
3. DispatchMove exchange files and ledger.
4. SDD + docsMove task evidence and durable documents.
5. FinishPersist PR/retro and remove old paths.
Clean-break rule: do not support dual-write compatibility. Provide one explicit migration command for unfinished runs, update every consumer, then reject legacy paths with a clear error.
