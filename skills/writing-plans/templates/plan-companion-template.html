Account Lockout Implementation Plan

For agentic workers: Execute each task with TDD and stop at every User Story checkpoint.

Spec: docs/superpowers/features/account-lockout/design.md

Goal: Lock an account after repeated failed sign-in attempts.

Architecture: Keep lockout policy in the authentication service and persist attempt state with the account record.

Tech Stack: TypeScript, PostgreSQL, Vitest

Expected Outcome

Working behavior

  • US-1: users are locked out after five failed sign-in attempts.

Artifacts

  • src/auth/lockout.ts owns the lockout policy.

How to see it working

Run npm test -- lockout.test.ts; observe the fifth failed attempt returning AccountLocked.
